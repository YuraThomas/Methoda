# Manual
В данном репозитории имеется несколько глобальных разделов (подробнее про каждый раздел можно почитать в их README)

**Examles_lectures** - примеры по цифровой схемотехнике (простейшие)

**my_UART** - так уж вышло, что один сеньор решил пинать меня до тех пор, пока моя простейшая и наивная реализация
UART не станет чем-то приемлимым, также там лежит статья про конечные автоматы.

**RISC_V_lectures** - лекции по высшей цифровой схемотехнике и код к лекциям

**chip_des_school** - решаю Школу Синтеза, сюда закидываю код решенных задач
