**SQRT_fun** - задания на подключение волшебной коробочки с корнями

**Poisk.v** - поиск кодовой последовательности **110011** через конечные автоматы

**detect_6.sv** - посик кодовой последовательности **110011** через сдвговый регистр

**delimost_na_5.sv** - проверяет делимость на 5, число задается побитово, новые биты - слева

(если, например, новый бит = 1, то число_после = 2 * число_до + 1)
