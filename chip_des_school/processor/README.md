# Тут задачи про добавление инструкций в готовый процессор

**JAL.meme** - бинарник для проверки реализации инструкции **JAL**

**instruction_rom.sv** - память инструкций процессора (не менялась)

**mul.sv** - модуль многотактного умножения для реализации **MUL** в **RV-32M**

**register_with_rst.sv** - D-триггер с RST, как я понял, является частью счетчика

**sr_alu.sv** - АЛУ, его я не менял (MUL у меня отдельно

**sr_control.sv** - один из кусков декодера инструкций, добавил в нем возможность останавливать проц, пока **MUL** считается и возможность **JAL**

**sr_decode.sv** - тут добавляюится константы (я добавил **IMM_J**)

**sr_cpu.sv** - opcede, func3, func7, alu_op (файл с константами)

**sr_register_file** - регистровый файл процессора

**srat_cpu** - само ядро процессора
