# Код к лекции про АЛУ

**ALU_1.v** - код к 1 примеру лекции 1 (простейшее прикольное АЛУ)

**ALU_2.v** - код к 2 примеру лекции 1 (АЛУ более-менее близкое к реальности, но без параметризированного нейминга операций и без флагов)

**ALU_3.v** - код к 3 примеру лекции 1 (АЛУ примерно к RISC-V простейшему), есть параметризация opcode и флаг условного перехода (C)

**modules** - модули, которые подрубаются к АЛУ,  реализовал я это так только ради красивой картинки в RTL-viewer, можно их легко вручную написать.
