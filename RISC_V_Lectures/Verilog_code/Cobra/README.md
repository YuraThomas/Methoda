# Код на Verilog к лекции 4 про Cobra

Если дать краткое описание про то, что есть Cobra, то это недо RISC-V, который поддерживает команды типа Register-Register, Register-Immediate, Branch 
(то есть, такой продвинутый программируемый  вычислятор, который умеет в циклы и if, но без внешней памяти и с несколько ограниченным функционалом)

**ALU** - АЛУ к Cobra

**Register_file** - регистровый файл к Cobra

**command_memory** - память команд к Cobra (сюда прошивку зашиваем)

**mux_RF** - мультиплексор на data_in в регистровый файл (выбирает, что загружать в него)

**cobra.v** - описание ядра Cobra на Verilog

**Proshivka** - примеры прошивки Cobra, которую мы писали вручную на лекции 5
